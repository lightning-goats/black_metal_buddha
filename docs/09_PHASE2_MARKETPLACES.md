# Phase 2 — Marketplace Expansion

Begin only after the direct store is stable.

## Candidate sequence

### 1. Etsy

Good initial fit for niche art/apparel. Printful supports direct listing/order integration.

Plan:

- production-partner disclosure as required
- optimized photography
- marketplace titles/tags
- fee-aware pricing
- shipping/return policy

### 2. Amazon

Printful supports Amazon.

Expect:

- Professional Seller account
- referral fees
- GTIN exemption commonly needed for POD products
- heavier compliance/listing work

### 3. eBay

Printful supports eBay.

Plan around:

- flat-rate shipping where live rates are unavailable
- fixed-price listings
- fees
- new-seller limits

### 4. TikTok Shop / another channel

Only if audience data supports it.

## Pricing

For each channel:

```text
retail
- marketplace fee
- payment fee
- Printful product
- Printful shipping
- expected problem/return allowance
= contribution margin
```

Do not blindly use one price everywhere.

## Catalog governance

Maintain:

```text
BMB SKU
Printful variant
BMB.com active?
Etsy active?
Amazon active?
eBay active?
channel listing ID
channel price
```
